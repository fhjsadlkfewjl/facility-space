# Частые вопросы

Все действия по шагам: [инструкция для сотрудников и АХО](facility-space-guide-ru.md).

## Доступ

Сотрудник работает со своим местом и бронями. АХО управляет объектами в разрешённых зданиях. Администратор настраивает доступ и общие справочники.

Общий демонстрационный код не является личной учётной записью: «Моё место» и «Мои бронирования» относятся к заданному для него пользователю.

## Карта и места

| Вопрос | Ответ |
|---|---|
| Коллега найден, но места нет | Постоянное назначение не указано; уточните у АХО |
| «Занято» означает присутствие? | Нет, это закрепление места, а не отметка присутствия |
| Можно занять место с будущей бронью? | Постоянное назначение блокируется действующей или будущей бронью |
| Выделенный стол уже забронирован? | Выделение только открывает карточку; бронь создаётся отдельным действием |
| Почему цвета поменялись? | Они зависят от режима карты; смотрите легенду |
| Нужного этажа нет | Сообщите АХО; в приложении могут быть не все этажи здания |

При бронировании проверьте дату и часы, особенно при работе из другого часового пояса: отображение использует настройки устройства.

## Редактор и площади

| Проблема | Что сделать |
|---|---|
| Кабинет не выделяется | Возможно, он нарисован только на фоне SVG. Проверьте наличие помещения и контура |
| После удаления контура стены остались | Это линии исходного SVG; контур объекта и фоновый рисунок — разные вещи |
| Помещение не удаляется | Прочитайте причину: могут оставаться мебель, договоры или другие связи |
| Размеры мебели неизвестны | Уточните шаблон или обмер; случайные размеры не вводите |
| Нет расчётной площади | Проверьте контур и масштаб. Документальную площадь можно внести отдельно |
| План изменён другим пользователем | Загрузите актуальную версию и сверяйте правки перед повторным сохранением |

м² на сотрудника — площадь, делённая на число постоянно размещённых сотрудников. м² на место — площадь, делённая на все рабочие места, включая свободные. Неизвестная площадь не равна нулю.

## Импорт и сохранение

Скачанный шаблон CSV содержит заголовки. Добавьте от 1 до 500 строк данных; файл XLSX не подходит. Используйте ID существующих связанных объектов, затем проверьте результат до применения.

Загрузка SVG добавляет фон плана, но не создаёт автоматически помещения, мебель или сотрудников. Их нужно проверить и добавить отдельно.

Статус «Решено» у замечания не исправляет сам объект. Журнал истории тоже не является кнопкой отмены. Для коррекции выполните новое действие.

Если результат сохранения непонятен, сначала обновите данные и проверьте их. При повторяющейся ошибке передайте ответственному раздел, здание, этаж, объект, действие и снимок ошибки. Код доступа не включайте.
