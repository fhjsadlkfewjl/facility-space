Facility Space

Инструкция для сотрудников и АХО.

Вход

Откройте https://2.29.173.184. Вставьте выданный код в «Access token» → «Войти».

Сотрудник видит карту, людей и свои бронирования. АХО дополнительно работает с помещениями, мебелью и размещением. Состав меню зависит от доступа.

Если при сохранении открылось окно проверки значений, проверьте данные → «Подтвердить». Дождитесь сообщения об успешном сохранении.

Сотруднику

Открыть карту

«Карта» → выберите здание и этаж → нажмите на стол или помещение. Справа откроется карточка.

«+» и «−» меняют масштаб. «Весь этаж» показывает план целиком. В «Здания» можно сначала выбрать офис, затем этаж.

Найти человека или кабинет

Нажмите поиск вверху → введите фамилию, название помещения или номер места → выберите результат. Для сотрудника с назначенным местом доступен переход на карту.

«Место не назначено» означает, что расположение человека в системе не указано.

Занять место

Откройте свободный стол → «Занять». Если у вас уже есть место, проверьте старое и новое расположение и подтвердите перенос.

Чтобы отказаться от своего места: откройте его карточку → «Освободить место» → «Освободить». Сам стол останется на карте.

Забронировать место

Откройте стол → «Забронировать» → укажите дату и время → подтвердите. Для нескольких дней включите «Несколько дней».

Чтобы сначала подобрать место: «Карта» → «Забронировать место» → период → «Показать свободные» → выберите результат.

Свои записи смотрите в «Мои бронирования». Ненужную бронь отмените в её карточке.

Назначение закрепляет стол постоянно. Бронь резервирует его на выбранное время.

Статусы на карте

- Свободно — нет текущего назначения или брони; возможность действия уточняется в карточке.
- Занято — место закреплено за человеком. Это не отметка его присутствия в офисе.
- Бронь — место зарезервировано на время.
- Недоступно — место выведено из использования.
- Выбранный объект — открытая вами карточка, а не бронь.

АХО

Сегодня

Сводка и быстрые переходы к рабочим разделам. Замечания к данным открываются в «Качество данных».

Найти свободное рабочее место

«Рабочие места» → выберите здание и этаж → включите «Только места без назначений и броней».

«На карте» показывает расположение. Для конкретных дат используйте «Бронирования» или на карте «Найти место на время».

Назначить или пересадить сотрудника

«Рабочие места» → у нужного стола меню «⋯» → «Назначить сотрудника» → введите минимум две буквы фамилии → выберите человека.

Проверьте место → «Подтвердить назначение». Если сотрудник уже занимает другой стол, проверьте перенос → «Перенести на это место». Прежнее место освободится.

Снять назначение

Откройте занятый стол на карте → «Снять назначение» → проверьте имя и номер места → «Подтвердить».

В реестре это действие также есть в меню «⋯». Там подтверждение открывается отдельным окном браузера.

Вывести место из использования

«Рабочие места» → меню «⋯» → «Вывести из использования» → подтвердите. Когда стол снова доступен, выберите «Вернуть в использование».

Занятое или забронированное место сначала нужно освободить. Для нескольких мест отметьте строки галочками и используйте действия над таблицей.

Изменить помещение

«Помещения» → выберите комнату → «Редактировать».

Заполните название, «Назначение помещения» — кабинет, санузел, коридор и т. п. — и площадь по документам. Если площадь неизвестна, оставьте поле пустым. Укажите основание → «Применить изменения помещения» → «Подтвердить».

Для нескольких комнат: отметьте строки → выберите «Новый тип» → «Предпросмотр изменений» → проверьте список → «Подтвердить изменение типов».

Проверить мебель

«Инвентарь» → найдите предмет → меню «⋯» → «Проверить». Заполните инвентарный номер, состояние и примечание → «Подтвердить проверку» → «Подтвердить».

Расположение можно посмотреть через «На карте». После проверки в списке обновится дата.

Добавить шаблон мебели

«Библиотека мебели» → форма добавления шаблона. Укажите название, категорию и реальные ширину и глубину в метрах. Для стола отметьте, что это рабочее место. При необходимости добавьте SVG-изображение → сохраните и подтвердите.

Шаблон — образец мебели. Предмет на этаже появляется после размещения в редакторе.

Подтвердить масштаб плана

«Карта» → нужный этаж → «Действия этажа» → «Выбрать две точки». Отметьте на плане концы отрезка, реальную длину которого знаете.

Снова откройте «Действия этажа», укажите расстояние в метрах и основание → «Подтвердить масштаб и рассчитать» → «Подтвердить».

Масштаб нужен для площади по контуру и размещения шаблонов с размерами в метрах.

Изменить планировку

«Редактор планировки» → выберите здание и этаж.

- Новая комната: «Нарисовать помещение» → название и тип → нажимайте по углам комнаты → «Завершить контур».
- Изменить границу: выберите комнату → перетаскивайте точки. «+» на линии добавляет точку. Выбранную точку убирает «Удалить выбранную точку».
- Нарисовать границу заново: выберите комнату → «Перерисовать контур» → отметьте углы → «Завершить контур».
- Убрать границу: «Убрать только контур» → подтвердите в окне браузера. Комната, мебель и назначения сохранятся.
- Удалить комнату: выберите пустую комнату → «Удалить помещение» → «ОК» → «Сохранить изменения». Комната исчезнет из активного списка. При связанных объектах система может запретить удаление.
- Добавить мебель: вкладка «Мебель» → раскройте «Добавить мебель» → выберите шаблон → проверьте размеры и номер места → «Указать место на плане» → нажмите в нужной точке. Для шаблона с размерами в метрах сначала подтвердите масштаб.
- Переместить или повернуть мебель: выберите предмет → перетащите его либо используйте поворот на 30°.

«Назад» отменяет правку, «Вперёд» возвращает. «Отменить всё» сбрасывает черновик после подтверждения.

В конце нажмите «Сохранить изменения». Все правки сохраняются вместе. До сохранения не закрывайте страницу.

Удаление контура не стирает линии фонового SVG. Его отображением управляет «Исходный план».

Создать или отменить бронь

«Бронирования» → «+ Бронирование» → выберите вид ресурса, период, здание, место и сотрудника → подтвердите создание.

Если ресурс занят, выберите другое место или время. Для отмены найдите запись → «Отменить бронь» → подтвердите действие в открывшейся панели.

Парковка

Добавить место: «Парковка» → «+ Добавить место» → здание, номер и площадь → «Добавить».

Назначить: «Управление парковкой» → найдите и выберите сотрудника → место → автомобиль или номер → «Назначить / перенести» → подтвердите.

Снять назначение: в той же форме выберите сотрудника с парковочным местом → «Снять назначение» → проверьте имя и номер в окне браузера и подтвердите.

Зона: выберите место в блоке «Зона парковки» → введите зону → «Сохранить» → подтвердите.

Тариф: заполните здание, цену за место в месяц, валюту и даты в блоке тарифа → «Сохранить» → подтвердите. Дата «до» в период не входит.

Аренда

Арендатор: «Аренда» → «+ Арендатор» → название, вид и реквизит компании при наличии → «Сохранить» → подтвердите.

Договор: «+ Новый договор» → арендатор, номер, даты и валюта → найдите и отметьте помещения → укажите ставки и способ учёта общих площадей → «Проверить и рассчитать» → проверьте состав и сумму → «Подтвердить договор».

Изменение условий: откройте договор и форму изменения условий. Укажите дату начала новых условий, площадь, ставку и основание → сохраните и подтвердите. Прежние условия сохраняются отдельным периодом.

Сумма — расчёт по введённым данным, а не выставленный счёт.

Площади и стоимость

Выберите здание и этаж. «По документам» — внесённая площадь; «по контуру» — расчёт по границе и масштабу. Прочерк означает, что данных не хватает, а не нулевую площадь.

Добавить ставку: «+ Новая ставка» → тип помещения, область действия, цена за м², валюта, период и даты → «Сохранить тариф».

Закрыть период: у нужной ставки «Изменить период» → «Не действует начиная с» → дата → «Закрыть период» → подтвердите.

Пример: 25 м² × 100 ₽/м² в месяц = 2500 ₽ в месяц. Без площади или подходящего тарифа полного расчёта не будет.

Качество данных

Выберите здание, найдите замечание → «Проверить». Укажите статус, комментарий и что проверили, на основании какого документа → «Сохранить» → «Подтвердить».

Для исправления самого объекта используйте «На карте» или его карточку. Завершение проверки само по себе не меняет площадь, контур или инвентарный номер.

Добавить здание

«Здания» → «+ Новое здание». Пройдите шаги: название, город и адрес → этажи → SVG-планы → помещения → проверка.

Добавляйте этажи через «Добавить этаж», комнаты — через «+ Помещение». У комнаты укажите название, тип и известную площадь.

На шаге «SVG планы» нажмите «План этажа 1» (или нужного этажа) → выберите SVG-файл до 3 МБ → дождитесь «План загружен». Размер плана определяется из SVG; физический масштаб настраивается отдельно на карте.

«Проверить перед созданием» → проверьте результат → «Создать здание и открыть первый этаж».

Импорт данных

«Импорт данных» → тип данных → «Скачать шаблон CSV». Заполните от 1 до 500 строк под заголовками и сохраните CSV.

Загрузите файл либо вставьте его текст в «Посмотреть / вставить CSV» → «Проверить файл» → исправьте ошибки → проверьте создаваемые и изменяемые записи → «Применить проверенные изменения».

Шаблон без заполненных строк импортировать нельзя. Проверка ничего не сохраняет; применение меняет данные. Общей отмены применённого импорта нет.

Настройки

Здесь добавляют типы помещений: «Тип помещения» → код, название и класс → «Сохранить» → подтвердите.

Код — от 2 до 40 строчных латинских букв и знаков подчёркивания, например `meeting_room`. Тип конкретной комнаты выбирается в её карточке.

Ответственные

Выберите здание или найдите человека. Раздел показывает, кто отвечает за офис. Назначения ответственных меняет администратор; они определяют доступ АХО к зданиям.

История

Откройте «История» и найдите объект или действие. В журнале видны автор, время и изменение. Историю отдельного объекта можно открыть из его карточки. Это журнал, а не отмена сохранённых действий.

Если возникла ошибка

Прочитайте сообщение рядом с действием. Проверьте, сохранился ли результат, прежде чем повторять операцию.

Если проблема осталась, отправьте ответственному здание, этаж, объект, описание действия и снимок ошибки.
