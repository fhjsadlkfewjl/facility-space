# Площади и спорные записи

## Исправление в приложении

«Помещения» → комната → «Редактировать». Укажите название, тип, площадь по документам и основание → примените изменения. Пустая площадь сохраняется как неизвестная. Устаревшая форма отклоняется, прежние значения остаются в истории.

В «Качество данных» фиксируют результат проверки. Для исправления поля открывают сам объект. Спорное назначение разрешают по подтверждению АХО; запись без этажа связывают с подтверждённым этажом. Исключение записи требует основания и не удаляет исходные сведения.

## Расчёты

- м² на сотрудника = площадь / число постоянно размещённых сотрудников.
- м² на место = площадь / число рабочих мест, включая свободные.
- Площадь по документам имеет приоритет над расчётной.
- При неполных данных общий показатель не рассчитывается.

Оценка масштаба по известным комнатам использует медиану `sqrt(документальная площадь / площадь контура)`. Для автоматического подтверждения нужны минимум три образца без расхождения площадей свыше 10%. Это проверка согласованности, а не замена обмера. Применение требует основания и актуальной версии плана.

## Результат исследования 11 ноября 2026

Из 1 299 активных помещений исходной выгрузки у 493 площадь корректна, у 805 пуста, у одного некорректна. 806 неизвестных значений уже отсутствовали в источнике.

Предварительную оценку масштаба прошли девять этажей; на них найдено 18 пригодных контуров без документальной площади. Эти оценки к реальным данным не применялись.

Проверки того обновления включали API, импорт, геометрию, браузерные формы и чтение реальной карты. Актуальные результаты: [проверки проекта](validation-final.md).
