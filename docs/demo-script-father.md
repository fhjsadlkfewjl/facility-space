# Короткий показ приложения

Откройте https://2.29.173.184 и войдите с выданным доступом. Сохранение показывайте на отдельных тестовых объектах; реальные назначения не меняйте.

Начало: «Facility Space объединяет планы офисов, сотрудников, рабочие места и учёт АХО. Здесь перенесённые карты и данные, с которыми можно работать через браузер».

| Экран | Что показать и сказать |
|---|---|
| Здания | Выберите офис и этаж: «Отсюда открывается нужный план» |
| Карта | Нажмите стол и комнату: «У каждого объекта есть карточка и доступные действия» |
| Люди | Найдите фамилию → «На карте»: «Можно найти рабочее место коллеги» |
| Рабочие места | Включите фильтр свободных: «АХО назначает, переносит и снимает сотрудника с места» |
| Бронирования | Откройте создание: «Это резерв на время, например на день приезда» |
| Помещения | Откройте редактирование: «Здесь название, тип и площадь по документам» |
| Инвентарь | Найдите предмет: «Можно сверить номер, состояние и дату проверки» |
| Редактор планировки | Покажите контур и мебель: «Правки сначала находятся в черновике, затем сохраняются вместе» |
| Библиотека мебели | «Здесь образцы мебели для размещения на этажах» |
| Парковка | «Реестр мест и назначения сотрудникам» |
| Аренда | «Договоры, помещения, общие площади и расчёт по условиям» |
| Площади и стоимость | «Расчёт зависит от введённых площадей и ставок» |
| Качество данных | «Здесь видно, что нужно сверить или дополнить» |
| История | «Можно посмотреть автора, время и содержание изменения» |
| Импорт данных | «CSV проверяется до применения» |
| Ответственные и Настройки | «Здесь доступ АХО к зданиям и справочники» |

**Отличие от Atlas:** «Atlas показывал идею интерфейса. Здесь есть сервер, база, сохранение действий, проверки конфликтов и история».

**До корпоративного запуска:** «Нужно подключить личный вход и обновление сотрудников, настроить внешние копии и уведомления, проверить данные и принять рабочие сценарии с АХО».
