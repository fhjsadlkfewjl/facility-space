# Показ Facility Space — 7–10 минут

Перед показом: открыть http://127.0.0.1:5173/, выбрать «АХО»; для полномочий вне назначенных зданий использовать «Администратор». В рабочей базе не создавать демонстрационные договоры, сотрудников и случайные площади. Изменения показывать на отдельной тестовой базе или останавливаться до подтверждения.

**Начало:** «Atlas показывал идею новой карты. Здесь уже приложение с сервером, базой и реальными перенесёнными данными. Покажу основные рабочие действия и отдельно — что нужно для запуска в компании».

| Время | Куда нажать | Что говорить |
|---|---|---|
| 0:00–0:45 | Обзор АХО | «Здесь вопросы, с которыми работает АХО: помещения, места, назначения, брони, замечания и аренда. Каждая карточка открывает рабочий раздел. Неизвестные площади показаны отдельно». |
| 0:45–1:30 | Здания → АЛЬФА → 8 | «Это восстановленный план реального этажа. Активные и неактивные старые этажи разделены. Мебель по возможности использует исходный рисунок». |
| 1:30–2:10 | Нажать стол, затем комнату | «Стол связан с рабочим местом и сотрудником. У комнаты видны обе площади, люди и места. АХО может исправить параметры с указанием основания». |
| 2:10–2:40 | Настроить масштаб… (раскрыть, не сохранять) | «Можно указать два конца известного расстояния. После подтверждения система пересчитает площади контуров, сохранив площадь по документам отдельно». |
| 2:40–3:10 | Помещения → строка → карта | «Карта нужна для выбора места, таблица — для работы со списком. Из строки переходим к нужной комнате». |
| 3:10–3:40 | Инвентаризация; Рабочие места | «Мебель можно сверять по номеру и состоянию. В реестре мест АХО назначает сотрудника, переносит или снимает назначение с подтверждением». |
| 3:40–4:20 | Роль «Сотрудник» → карта → выбрать будущий интервал и свободный стол | «У сотрудника упрощённое меню. Он работает только со своим размещением и бронями. Для выбранного времени карта показывает доступность; сервер ещё раз проверяет конфликты». Не создавать бронь в рабочей базе ради показа. |
| 4:20–4:40 | Бронирования → роль АХО → Парковка | «Бронь нужна для временного приезда, постоянное назначение — для обычной рассадки. Парковочный механизм готов, реальные места и правила нужно получить у компании». |
| 4:40–5:20 | Качество данных | «Это конкретные пропуски и противоречия источника. Статус проверки сам по себе не исправляет данные. Для помещения открываем карточку, для спорного назначения нужно подтверждённое решение». |
| 5:20–5:50 | Площади и стоимость | «Ставки имеют периоды действия, площади — историю. Полнота расчёта зависит от подтверждённых данных. Отсутствующие сведения не заменены выдуманными». |
| 5:50–6:40 | Аренда → Создать договор | «Выбираем арендатора и офисы. Общие площади можно добавить конкретными комнатами, долей либо величиной из договора. До сохранения показываются состав и месячная плата. Реальные договоры ещё не загружены». Для примера расчёта использовать скриншот тестового договора, пометив его тестовым. |
| 6:40–7:20 | Библиотека мебели; Импорт данных | «Новые типы мебели добавляются с реальными размерами и SVG. Большие списки загружаются через проверку и предпросмотр; повторное применение и незаметная перезапись блокируются». |
| 7:20–8:10 | Редактор планировки → существующий предмет → поворот 30° → назад/вперёд → версии | «Редактор хранит положения и историю версий. Показать поворот и отменить; не сохранять изменение в рабочем плане ради демонстрации». |
| 8:10–9:00 | Настройки объектов → Добавить здание | «Начальное создание здания и этажей с планами уже возможно без программиста. Полный объединённый мастер со всеми импортами ещё предстоит довести». |

**Что сделано за это время:** «Восстановлены данные и планы 58 активных этажей; 19 неактивных сохранены отдельно. Кроме карты работают назначения, брони, учёт, исправления, история, расчёты, импорт и новые сценарии аренды. Это уже действия с проверками и сохранением, а не только макеты экранов».

**Почему не объявляем корпоративный запуск:** «Нужны корпоративный вход, актуализация людей, размещение и приёмка АХО. Кроме этого у нас ещё есть инженерные задачи по полному новому заданию; они перечислены в контрольном списке. Говорить, что осталось только получить сервер, было бы неправдой».

**Что просим после показа:** «Контакт IT для входа, данных и размещения; ответственного АХО для проверки площадей, рассадки, парковки и договоров. С нашей стороны — закрыть обозначенные инженерные задачи и пройти согласованные проверки».

Если экран не сработал: «Зафиксирую замечание. Следующий сценарий покажет отдельную часть системы».
