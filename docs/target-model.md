# Дальнейшее развитие

Текущая структура описана в [модели данных](current-model.md), задачи запуска — в [списке работ](gap-list.md).

Следующие изменения требуют согласования: регулярная синхронизация, правила объединения новых выгрузок с ручными правками, расширенные операции аренды, массовый перенос между этажами и исторические расчёты за периоды.

Подтверждённые площади, размеры, классификация и правила рассадки остаются ответственностью компании. Расширение модели не должно заменять отсутствующие сведения предположениями.
