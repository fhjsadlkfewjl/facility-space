# Приёмка АХО

Проверки с изменением данных выполняются на тестовых объектах в отдельной копии. Для каждого пункта запишите результат и замечания; после проверки удалите тестовые записи.

- [ ] Вход каждой роли; запрет чужих действий и изменений вне разрешённых зданий.
- [ ] Выбор здания и этажа, открытие SVG, выбор стола и комнаты.
- [ ] Поиск сотрудника и переход к правильному месту.
- [ ] Занятие, перенос и освобождение своего места с подтверждением.
- [ ] Назначение и снятие сотрудника через АХО; отключение свободного места.
- [ ] Создание и отмена брони; отказ при пересечении и постоянном назначении.
- [ ] Парковочное назначение, перенос и снятие.
- [ ] Изменение типа и площади помещения с основанием; просмотр истории.
- [ ] Инвентаризация: номер, состояние, дата проверки и переход на карту.
- [ ] Редактор: рисование, точки, мебель, удаление пустой комнаты, отмена и общее сохранение.
- [ ] Два пользователя редактируют один план: устаревшая версия отклоняется.
- [ ] Импорт CSV: правильный файл, ошибки, повторное применение и отсутствие частичного сохранения.
- [ ] Аренда и тарифы: состав, площадь, даты, расчёт и изменение условий.
- [ ] Замечания к данным: исправление объекта и сохранение решения.
- [ ] Экспорт отчётов и отсутствие финансовых данных у сотрудника.
- [ ] Обновление, откат и восстановление проверены IT в целевой среде.
