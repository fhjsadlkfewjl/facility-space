# Подготовка к запуску

- [ ] IT назначил ответственного за сервер и базу.
- [ ] Корпоративный вход проверен для сотрудника, АХО и администратора.
- [ ] Утверждены права АХО на здания и порядок отзыва доступа.
- [ ] Настроено обновление сотрудников и подразделений.
- [ ] АХО проверил выбранные этажи, назначения, площади и типы помещений.
- [ ] Для используемых разделов внесены парковочные места, договоры и тарифы.
- [ ] Пройдены [сценарии приёмки](uat-checklist.md), блокирующие ошибки исправлены.
- [ ] Проверены нагрузка, обновление и откат в среде компании.
- [ ] Копия хранится вне сервера; восстановление проверено.
- [ ] Уведомления о сбоях доходят до ответственного.
- [ ] Переданы доступы, [инструкция](user-guide/facility-space-guide-ru.md) и [комплект восстановления](../deploy/handoff/RESTORE.md).

Результат отмечают после проверки, с датой и ответственным. [Состояние разработки](status.md) и [ограничения](gap-list.md) ведутся отдельно.
