# Что спросить у АХО после показа

1. **Правильно ли названы и классифицированы помещения?** Кто проверит кабинеты, общие и технические зоны на выбранных этажах?
2. **Какие площади и планы считать подтверждёнными?** Нужны документы/обмеры, контрольные расстояния и даты действия площадей. Где нет данных, приложение не должно придумывать площадь.
3. **Кто разберёт спорные назначения и неполные записи?** Исходный карантин: 518 назначений, 11 объектов, 17 помещений без этажа и один неактивный ресурс. Нужны решения с основанием.
4. **Как устроена парковка?** Нужны реестр мест/зон, разрешённые сотрудники и правила постоянного назначения, брони и отмены.
5. **Как считать стоимость и аренду?** Передайте реальные тарифы, валюты, периоды, договоры и арендаторов. По каждому договору подтвердите модель общих площадей: нет / конкретные помещения / доля / площадь по договору. Отдельно согласуйте неполные месяцы, налоги, продление и завершение договора; этих правил нельзя вывести из карты.
6. **Кто примет систему?** Назначьте двух-трёх пользователей, здания для UAT, сценарии проверки и человека, который подтвердит результат. Сначала проверяем утверждённые сценарии, затем фиксируем замечания и критерии запуска.
