# Как трактовать исходные данные

- SQL-выгрузка и снимки редактора сделаны в разное время. Отсутствие объекта в одном из них не доказывает удаление.
- У 19 этажей в исходнике стоит `ACTIVE=false`. Причины — архивирование, замена или удаление — по этим данным не определены.
- Координаты SVG не равны метрам. Предполагаемый масштаб не заменяет подтверждённый обмер.
- Пустая площадь означает отсутствие данных, а не ноль. История до первого известного значения неизвестна.
- Спорное назначение требует решения АХО. Совпадение подразделения или комнаты не определяет владельца места.
- Парковки, договоры и тарифы заполняются по сведениям компании.
- Повторный импорт одного снимка проверен; автоматическое слияние нового снимка с ручными правками не предусмотрено.
