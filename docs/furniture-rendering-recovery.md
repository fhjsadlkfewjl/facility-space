# Отображение импортированной мебели

По проверке 11 ноября 2026 года в снимках 58 этажей найден 21 шаблон мебели. У каждого есть исходный SVG и размер рисунка; у семи также есть отдельная базовая фигура `basis`.

На активных этажах доступных зданий проверены 4 235 предметов. У 502 не заполнено отдельное поле ширины, но размер SVG известен.

При отображении учитываются размер рисунка, точка привязки `box.cx/box.cy` и масштабирование по `basis`. Прозрачная область нажатия соответствует рисунку. Условная рамка нужна только при отсутствии пригодного рисунка и размеров.

Размер рисунка в координатах плана не подтверждает физические размеры мебели. Площади и назначения этим исправлением не менялись. Проверены исходная привязка, масштабирование и отображение при недостатке данных.
