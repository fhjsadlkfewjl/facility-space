# Устройство проекта

Интерфейс — React и Vite, API — Fastify и TypeScript, база — PostgreSQL. Для локальных тестов и импорта используется PGlite. Схема базы хранится в [миграциях](../db/migrations).

## Основные данные

- Здание → этаж → помещение. Мебель относится к этажу и, если связь известна, к помещению.
- Шаблон задаёт вид и размеры мебели. Рабочее место — отдельная запись, связанная с предметом мебели.
- Сотрудники и подразделения импортированы из внешнего справочника.
- Постоянные назначения и временные бронирования хранятся отдельно, с историей.
- Парковочные места, назначения и тарифы отделены от офисной мебели.
- Договор аренды содержит помещения или распределённые площади и периоды условий.

## Площади и геометрия

Документальная площадь и площадь по контуру хранятся раздельно. Для расчёта по контуру нужен подтверждённый масштаб этажа. Координаты SVG сами по себе не являются метрами.

SVG проходит проверку; скрипты и внешние ссылки не допускаются. Исходные идентификаторы и сведения об импорте сохраняются для сверки.

## Изменения

Назначения, брони и групповые операции выполняются транзакционно. Версия планировки защищает от перезаписи чужих правок. Восстановление плана создаёт новую версию; назначения не откатываются вместе с ней.

Журнал изменений и версии защищены от изменения обычными операциями базы. Владелец базы сохраняет административные полномочия.
