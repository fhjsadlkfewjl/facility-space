# Перенос Office Map

Правила переноса сохранённого снимка. Новый источник сначала проверяют в отдельной базе; рабочие правки автоматически не перезаписываются.

| Источник | Куда переносится | Правило |
|---|---|---|
| `BUILDINGS 133` | `buildings` | ID, имя, активность |
| `LEVELS 134.BUILDING_ID` | `floors` | Проверенная связь со зданием |
| `LEVELS.BG` и снимок редактора | Подложка этажа | Исходный SVG после проверки; координаты остаются единицами плана |
| `ZONES 135.LEVEL_ID/SHAPE` | Помещение и контур | Неподдерживаемый контур помечается для проверки |
| `ZONES.AREA` | Документальная площадь | Десятичная запятая поддерживается; пустое значение — `NULL` |
| `TPL 132.IS_TABLE` | Признак рабочего места в шаблоне | Значение enum 225=Y из выгрузки |
| SVG и геометрия шаблона | Шаблон мебели | Сопоставление по ID, затем по единственному нормализованному имени |
| `OBJECTS 136` | Мебель | Проверка этажа, шаблона и комнаты; комната другого этажа не назначается |
| `OBJECTS.POSITION` | Координаты и поворот | Формат `X:Y:R`, исходная строка сохраняется |
| Объект снимка редактора | Уточнённая геометрия | Только при совпадении ID объекта, этажа и шаблона |
| Базовая фигура шаблона | Ширина и глубина | Единицы SVG, не подтверждённые метры |
| `OBJECTS.INV` | Инвентарный номер и код места | При пропуске или повторе — служебный `LEGACY-ID` и проверка |
| Сотрудники и `table_num` | Справочник и назначения | Только однозначные активные связи; остальные — в карантин |

Классификация помещений хранит признак автоматического определения и уровень уверенности. История площади начинается с даты наблюдения, а не задним числом. Повтор того же снимка не добавляет записи импорта и аудита.

В сверке геометрии совпали 4 262 объекта, уточнены 104 положения или поворота. 32 объекта только в снимке редактора и 90 только в выгрузке оставлены для разбора. Подробно: [поэтажная сверка](reconciliation-report.md).
