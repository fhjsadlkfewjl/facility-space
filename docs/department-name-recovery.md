# Названия подразделений и фильтр карты

Проверено и применено 11 ноября 2026.

В меню удалён раздел «Команды». На карте этажа доступен фильтр «Подразделение»: только подразделения размещённых на этом этаже сотрудников. Остальные места приглушаются, таблица рабочих мест фильтруется. При смене этажа фильтр сбрасывается.

Источники проверены локально, без запросов и изменений старого портала:
- `portal_prod_redacted.sql`, SHA-256 в соседнем JSON-отчёте;
- сохранённый HAR (818 записей): отдельного пригодного справочника подразделений не обнаружено;
- настройки `b_user_field`: ENTITY_ID=USER, FIELD_NAME=UF_DEPARTMENT, USER_TYPE_ID=iblock_element, IBLOCK_ID=12;
- инфоблок 12 имеет название «Подразделения».

Ранее экстрактор сохранял только офисные инфоблоки 132–136 и не извлекал названия подразделений. Теперь он сохраняет названия из инфоблока 12 только при подтверждённой настройками связи пользовательского поля; импорт использует их по точному ID.

Из 3171 уникального ID, указанного у сотрудников, 3166 совпали с элементами справочника подразделений. Названия восстановлены в локальной базе; 5 ID отсутствуют в источнике и остались явно неподтверждёнными. Иерархия не угадывалась. Назначения, сотрудники, привязки к подразделениям и исходные записи не изменялись. Для каждого исправленного названия сохранены предыдущее значение, новое значение, ID источника, хеш выгрузки и автор в аудите.

Повторное применение не дублирует изменения, а попытка заменить уже подтверждённое название другим отклоняется.

Проверки: сборка, 7 тестов API/импорта, 2 Python-теста экстрактора; браузерная проверка фильтра на синтетических данных.
