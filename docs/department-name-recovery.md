# Восстановление названий подразделений

11 ноября 2026 года названия восстановлены из сохранённой выгрузки. Старый портал при этом не изменялся.

Поле пользователя `UF_DEPARTMENT` связано с инфоблоком 12 «Подразделения». Экстрактор проверяет эту связь и сопоставляет названия по ID.

Из 3 171 ID сотрудников 3 166 найдены в справочнике. Пять отсутствующих ID остались неподтверждёнными. Назначения и связи сотрудников не менялись. В аудите записаны прежнее и новое название, ID источника и хеш выгрузки. Повторное применение не дублирует изменения.

На карте фильтр «Подразделение» показывает подразделения размещённых сотрудников. Поиск доступен внутри списка. 25 ноября исправлена фильтрация таблицы объектов этажа; её проверяет браузерный тест.
