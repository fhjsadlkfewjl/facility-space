# Обновление от 15 ноября 2026

В существующее приложение добавлены аренда, библиотека мебели, калибровка, импорт и мастер здания. Импортированные данные и назначения сохранены.

| Раздел | Результат того обновления |
|---|---|
| Карта | Выбор периода брони, режим арендаторов, переключение карты и таблицы |
| Бронирование | Личное создание с карты; сервер проверяет конфликты |
| Мебель | Категории, проверка SVG, физические размеры и признак рабочего места |
| Площади | Калибровка по двум точкам, история, отдельная расчётная площадь |
| Импорт | Проверка CSV, сравнение и атомарное применение |
| Здание | Пошаговое создание с этажами, планами и помещениями |
| Аренда | Договоры, четыре способа учёта общих площадей, расчёт и история условий |

В том прогоне прошли сборка, 80 автоматических тестов, 19 браузерных сценариев, одна проверка реальной карты без изменения данных и шесть Python-тестов. Один тест PostgreSQL пропущен. Локальные замеры PGlite не были нагрузочной проверкой.

На тот момент оставались общий мастер массовой загрузки, расширенная аренда, часть связей карты с реестрами и проверки неполной геометрии. Более позднее состояние: [сводка](status.md) и [результаты проверок](validation-final.md).
