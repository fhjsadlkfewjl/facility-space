# Показ за 7–9 минут

Перед началом: открыть https://2.29.173.184, подготовить ключи `:employee` и `:admin`; проверить по smoke-листу выбранный этаж. Для полного показа интерфейса АХО использовать admin: зоны ответственности facilities ещё не назначены. Ключи не демонстрировать на общем экране.

**0:00–0:30 — начало.** «Я разобрал старую Office Map и перенёс реальные здания, планы, помещения, мебель и связи рабочих мест. Atlas показывал идею интерфейса. Здесь уже сервер, база и действия с проверками. Это рабочий пилот, который можно открыть удалённо без моего компьютера».

**0:30–2:30 — сотрудник.** Войти как employee → Карта → АЛЬФА → 8 этаж (если нужный объект на другом этаже, следовать результату поиска).
- «Сотруднику нужны карта, коллеги и своё место, без административных разделов».
- Люди → знакомая фамилия → На карте. «Поиск связан с реальным рабочим местом, когда назначение известно».
- Свободный стол → Назначить себе. Если есть место — показать явное подтверждение переноса. «Нельзя назначить за другого человека или занять уже занятое место».
- Бронирование → свободное место и будущий интервал. «Это временный резерв, например на день приезда. Он отличается от постоянного закрепления».
Изменения делать только на заранее выбранных местах: резервировать другое свободное место, не уже закреплённое. После показа снять своё тестовое назначение/отменить бронь. Не пересаживать реального сотрудника ради эффектного клика.

**2:30–6:30 — АХО.** Профиль → Выйти → admin → Сегодня.
- Рабочие места → поиск сотрудника → действие назначения/переноса. «АХО управляет размещением; перед изменением видно, кого и куда перемещаем». Для реального сотрудника достаточно показать форму, не подтверждать.
- Карта → помещение → параметры. «Название, назначение и площадь относятся к конкретной комнате, которую видно на плане».
- Импорт → выбрать тип → открыть шаблон/предпросмотр. «CSV сначала проверяется, только затем применяется. Повторно загружать старую базу для обновления сайта не нужно». Не применять неподготовленный файл.
- Планировка → существующий этаж → мебель/поворот/версия. «Расстановка редактируется на реальном плане, изменения имеют историю». Не сохранять случайную расстановку.
- Масштаб/площадь. «Расчёт по контуру требует контрольного размера. Площадь по документам вводится отдельно; неподтверждённый масштаб не выдаём за официальный».
- Инвентарь → поиск/карточка предмета. «Можно сверять объект и его инвентарный номер».
- Площади и стоимость. «Расчёт использует площади и тарифы. Реальные ставки пока не предоставлены, поэтому финансовый результат компании я сейчас не обещаю».

**6:30–7:30 — дополнительные возможности.** Коротко открыть Парковку, Аренду, Качество данных, Историю.
«Парковка и аренда реализованы, но реестры компании ещё не заполнены. Здесь замечания исходных данных: система их обнаруживает, АХО подтверждает правильные сведения. История позволяет понять, что менялось. Правила работы должен подтвердить АХО».

После этого я исправляю блокирующие проблемы и передаю IT комплект для размещения, входа и синхронизации. Общий демонстрационный ключ не заменяет корпоративные учётные записи».
