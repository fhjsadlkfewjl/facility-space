# Перед показом — 8 проверок за 10–15 минут

Для действий выбрать существующего демонстрационного пользователя local-reviewer и свободные места. Записать его исходное назначение. Не использовать чужие реальные назначения. Если нет подходящего свободного места/интервала — отметить проверку как не выполненную, не менять данные другого человека.

| № | Что нажать | Ожидаемый результат |
|---|---|---|
| 1 | HTTPS → войти employee; затем выйти/войти admin | Без предупреждения сертификата; правильное меню роли; без токена данные не открываются |
| 2 | Employee → Карта → здание → активный этаж | Реальный SVG, столы и кабинет; выбор этажа меняет карту |
| 3 | Люди → фамилия с известным назначением → На карте | Правильные здание/этаж, выбранное место. У человека без назначения — честное сообщение |
| 4 | Свободный стол A → назначить себе → стол B → подтвердить перенос → снять назначение | Назначение только себе; перенос явный; A освобождается; снятие подтверждается. Вернуть исходное назначение, если было |
| 5 | Свободное место → будущий интервал → забронировать → Мои бронирования → отменить | Бронь видна с верным временем и местом; после отмены резерв снят |
| 6 | Admin → Рабочие места → выбрать того же demo-пользователя → свободное место → перенос → снять | Место и сотрудник совпадают; предыдущая связь закрыта; чужие сотрудники не затронуты. Вернуть исходное состояние |
| 7 | Admin → Инвентарь → фильтр здания/предмета → карточка → На карте | Предмет находится; номер отображается либо явно отсутствует; карта соответствует объекту |
| 8 | Импорт → шаблон/предпросмотр; Планировка → реальный этаж; Сегодня | Формы открываются без ошибки; план и мебель видны; Сегодня содержит быстрые действия и один счётчик. Ничего не применять/сохранять |

Результат: 8 строк «пройдено / ошибка / не выполнено» + короткое описание. На текущем этапе автоматизированно проверены отдельные API/тестовые сценарии, а не весь этот ручной список на реальных назначениях. Полный QA не нужен для каждого показа.
