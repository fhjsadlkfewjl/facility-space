# Качество данных — это не тысячи незаконченных функций

Сейчас у администратора **2 380 открытых замечаний**, а не 2 380 отдельных объектов или разработческих задач. Один объект может иметь несколько причин. Число зависит от роли и доступа к зданиям. Значения получены из живого staging.

| Замечание | Что обнаруживает система | Кто и как закрывает |
|---|---|---|
| Нет официальной площади — 806 | Пустое поле | АХО получает документ/обмер и вводит площадь |
| Нет инвентарного номера — 523 | Пустое поле | АХО сверяет маркировку или учётный реестр |
| Дубликат номера — 6 | Повтор номера | АХО выясняет правильный номер; система не придумывает его |
| Нет масштаба — 56 | Нет калибровки | АХО даёт контрольный размер; затем калибровка и проверка расчётов |
| Проверить контур — 222 | Непригодная геометрия | Сверить план; исправить контур в редакторе. Ошибку инструмента исправляем мы |
| Мебель за помещением — 219 | Геометрическое несоответствие | АХО сверяет положение/размер и помещение; возможна неточность источника |
| Нет SVG — 1 | Нет плана | Сейчас это существующий тестовый этаж; предоставить план либо отдельно решить судьбу тестового объекта |
| Карантин переноса — 547 | Противоречия исходных связей | АХО решает, кому принадлежит место; IT помогает найти достоверный источник |

**IT нужен** для источников, синхронизации и стабильных ID, а не чтобы вручную заполнить каждую площадь. **Наша инженерная задача** — исправлять неверное обнаружение, ошибки сохранения и инструментов, а не выдумывать бизнес-данные.

Статус «Проверено/Решено» сам по себе не исправляет поле объекта. Исправление площади, номера или назначения выполняется соответствующим действием; комментарий объясняет решение. Не закрывать замечания только ради уменьшения счётчика. «Сегодня» показывает вход в эту очередь, а не требование всё сделать сегодня.
