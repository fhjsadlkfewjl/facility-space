# Обновление и передача IT

Обычное обновление запускается из корня проекта:

```sh
bash scripts/update-staging.sh
```

Текущий порядок резервирования, проверки кандидата и отката описан в [эксплуатации](../operations-ru.md). Рабочая база при обновлении не заменяется локальной.

Получателю передают исходники и [комплект восстановления](../../deploy/handoff/RESTORE.md). Реальные данные зашифрованы; ключ и доступы передаются отдельно.

До передачи согласуйте [вопросы IT](../it-questions-final.md) и [вопросы АХО](../aho-questions-final.md). Не запускайте повторный `init` и не удаляйте том базы для устранения ошибки обновления.
