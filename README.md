# Facility Space

Приложение для сотрудников и АХО: карта офиса, поиск людей, рабочие места, бронирования, парковка и управление помещениями.

## Что есть в проекте

- Карты этажей, помещения, мебель и рабочие места.
- Поиск сотрудников и переход к их месту на карте.
- Назначение мест, бронирования и парковка.
- Инвентаризация, площади, аренда и стоимость.
- Редактор планировки и история изменений.

Интерфейс — React и TypeScript. Сервер — Fastify. База — PostgreSQL.

## Запуск для разработки

Нужны Node.js 24 и Python 3.

```sh
npm ci
npm run build
npm run demo
```

Во втором терминале:

```sh
VITE_DEMO_TOKEN=local-demo-token-only npm run dev -w @office/web
```

Откройте http://localhost:5173. Этот запуск использует тестовые данные в памяти; после остановки они сбрасываются.

Проверки: `npm run test:source` и `npm run test:python`.

## Передача рабочего сайта

Код хранится здесь. Комплект с реальной базой, планами и готовой серверной версией передаётся отдельно вместе с инструкцией восстановления. Пароли и ключ расшифровки — отдельно от комплекта. Восстановление выполняется в новую базу.
